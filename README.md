# cup
Надстройка над пакетными менеджерами. Один интерфейс для установки, поиска
и удаления пакетов из разных источников.

## Статус

В активной разработке. Сейчас работает только `pacman`.
Остальное — в планах.

## Установка

Склонируй репу:
``` bash
git clone <url>
chmod +x cup.sh
```

Добавь alias в ~/.bashrc:
``` bash
alias cup='bash /path/to/cup.sh'
```
## Использование
~~~
cup install <пакет>     # установить пакет
cup remove <пакет>      # удалить пакет
cup update              # обновить систему
cup search <запрос>     # найти пакет
cup clean-cache         # очистить кэш пакетов
cup gitbuild <repo>     # собрать пакет из git-репозитория
~~~

Для gitbuild доступен флаг --no-install — собрать, но не устанавливать.

## Как это работает

cup ведёт локальную базу установленных пакетов в ~/.cup/db.sqlite3.
Каждая запись хранит имя, источник, версию, даты установки и обновления.

Планируется: единый поиск по нескольким источникам (pacman, AUR, flatpak,
snap, apt, ADB) с интерактивным выбором, откуда ставить.

## Зависимости

- bash
- sqlite3
- git
- pacman (для работы с пакетами Arch Linux)
- base-devel (для makepkg при сборке из AUR)

## Структура проекта

Пока один файл — cup.sh. Планируется разбить на слои:
db.sh, pkg.sh, cmd.sh.
